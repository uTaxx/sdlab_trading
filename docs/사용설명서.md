# muwon406 사용설명서

> 코스피·코스닥 종목을 매일 자동으로 분석해서 사고팔고, 그 결과를 폰으로 보여주는 시스템입니다.
> 지금은 **모의투자(가짜 돈)** 전용으로 돌아갑니다.

## 🔗 대시보드

**https://utaxx.github.io/sdlab_trading/**

폰·PC 아무 브라우저에서나 열립니다. 내 PC가 켜져 있을 필요 없습니다.
(폰 브라우저 메뉴 → "홈 화면에 추가"를 하면 앱처럼 아이콘이 생깁니다.)

## 1. 한 줄 요약

매일 장이 끝나면 자동으로,

1. 정해진 종목들의 그날 주가를 가져와서
2. 정해진 규칙(전략)에 따라 **살지 / 팔지 / 가만히 있을지**를 판단하고
3. 실제로 증권사(한국투자증권)에 모의투자 주문을 넣고
4. 결과를 **텔레그램으로 알려주고** 대시보드에 기록합니다.

사람이 아무것도 안 눌러도 알아서 돕니다. 내가 하는 일은 **결과를 보고 판단하는 것**뿐입니다.

## 2. 전체 그림

```
        [매일 평일 15:30]
              │
   GitHub Actions (자동 실행기)
              │
              ├── 한국투자증권 API ──▶ 주가 조회 / 모의투자 주문
              ├── 구글 드라이브    ──▶ 기록 파일(muwon.db) 저장·복원
              ├── 텔레그램         ──▶ 나에게 알림
              └── Streamlit 대시보드 ─▶ 폰으로 확인 / 설정 변경
```

| 부품 | 역할 | 쉬운 설명 |
|---|---|---|
| **GitHub Actions** | 자동 실행기 | 정해진 시간에 알아서 프로그램을 돌려주는 무료 서버. 내 PC를 안 켜도 됩니다. |
| **KIS API** | 증권사 창구 | 한국투자증권이 열어 준 프로그램용 창구. 주가를 묻고 주문을 넣습니다. |
| **muwon.db** | 장부 | 보유 종목·현금·주문 기록이 든 파일 하나. |
| **구글 드라이브** | 금고 | GitHub 서버는 실행이 끝나면 사라지므로, 장부를 드라이브에 넣고 매번 꺼내 씁니다. |
| **Streamlit** | 대시보드 | 인터넷에 올려둔 화면. 상태 확인 + 설정 변경. |
| **텔레그램** | 알림 | 매수·매도·경고를 폰으로 바로 보냅니다. |

> **API(에이피아이)**: 프로그램끼리 대화하는 규칙. 사람이 HTS 화면에서 마우스로 하던 걸, 프로그램이 대신 하게 해주는 통로입니다.

| 언제 | 무엇 | 결과 |

| 필요할 때 수동 | 주문 경로 점검 | 주문이 실제로 나가는지 강제로 1주 테스트 |

## 4. 무엇을, 어떤 기준으로 사고파는가

### 4-1. 어떤 종목을 보나

시가총액(회사 전체 가격) 상위 종목 **약 18~30개**만 봅니다. 코스피와 코스닥을 정해진 비율로 섞습니다.
ETF·ETN·스팩·우선주는 자동으로 걸러냅니다(성격이 달라 같은 규칙을 적용하면 안 됨).

> **시가총액**: 주가 × 총 주식 수. 회사를 통째로 사려면 드는 돈. 클수록 대형주.
> **ETF**: 여러 종목을 묶어 파는 상품. **스팩(SPAC)**: 인수합병용 껍데기 회사. **우선주**: 의결권 없는 대신 배당 우대되는 주식(삼성전자우 같은 것).

### 4-2. 지금 쓰는 전략: `ma_rsi_v1` (이동평균 + RSI 복합)

**살 때** — 둘 중 하나면 매수 신호:
- 20일 이동평균선을 주가가 위로 뚫으면서 + 거래량이 평소의 1.5배 이상
- RSI가 30 아래(과매도)까지 떨어졌다가 다시 올라올 때

**팔 때** — 하나라도 걸리면 매도:
- 20일 이동평균선을 아래로 뚫을 때
- RSI가 70 위(과매수)로 올라갔을 때
- 손실이 −5%에 닿았을 때 (손절)

> **이동평균선(MA)**: 최근 N일 종가의 평균을 이은 선. 20일선 = 최근 20일 평균. 주가가 이 선 위에 있으면 최근 흐름이 좋다는 뜻으로 봅니다.
> **RSI**: 0~100 사이 숫자로 "최근에 너무 올랐나/너무 빠졌나"를 재는 지표. 보통 30 아래는 과매도(많이 빠짐), 70 위는 과매수(많이 오름)로 봅니다.
> **거래량 급증**: 평소보다 훨씬 많이 거래됨 = 관심이 몰렸다는 신호.
> **손절**: 더 큰 손실을 막으려고 손해 본 채로 파는 것.

### 4-3. 리스크 규칙 (전략보다 위에 있는 안전선)

전략이 "사자"고 해도 아래 규칙에 걸리면 **안 삽니다.**

| 규칙 | 기본값 | 뜻 |
|---|---|---|
| 종목당 최대 비중 | 15% | 전 재산의 15%까지만 한 종목에 |
| 손절 라인 | −5% | 한 종목이 5% 빠지면 자동 매도 |
| 일일 손실 한도 | −3% | 하루에 전체가 3% 빠지면 그날 신규 매수 중단 |
| 동시 보유 종목 수 | 8개 | 최대 8종목까지만 |
| 자동매매 스위치 | ON | OFF면 신규 매수를 전부 거부 |

이 값들은 **대시보드에서 바로 바꿀 수 있고**, 바꾼 내역은 자동으로 기록에 남습니다.

### 4-4. 하루에 몇 번 사고파나

하루 **한 번** 판단합니다. 종목당 최대 1건이고, 대부분의 날은 **아무 신호가 없어서 거래 0건**입니다.
이건 고장이 아니라 정상입니다 — 조건이 까다로울수록 거래는 드물어집니다.

## 5. 급할 때: 자동매매 끄는 법 (킬스위치)

**방법 A — 대시보드 (가장 빠름)**
1. 대시보드 접속 → "리스크 정책" 펼치기
2. `자동매매` 토글을 끄고 저장

**방법 B — GitHub에서**
1. GitHub 저장소 → Actions → "KIS 모의투자 일일 자동매매"
2. `Run workflow` → `trading_enabled`을 `false`로 → 실행

끄면 **새로 사지 않습니다.** 이미 들고 있는 종목의 매도·손절은 계속 동작합니다(위험을 방치하지 않기 위함).

추가 안전장치:
- 실거래 계좌(`real`)로 설정되어 있으면 매매 스크립트가 **아예 실행을 거부**합니다.
- 주문 점검 스크립트도 모의투자 계좌에서만 돕니다.
- 종목 목록 갱신은 기본이 "미리보기"라, 확인 없이는 바뀌지 않습니다.

### 5-1. 이미 나간 주문을 되돌리는 법 (미체결 취소)

킬스위치는 **앞으로** 살 것을 막습니다. 이미 나간 주문은 못 막습니다.

주문이 일부만 체결되면 나머지(**잔여** — 주문했는데 아직 안 채워진 수량)가
장 마감까지 남습니다. 남아 있는 동안 그 주문은 **아직 살아 있어서**, 몇 분
뒤 값이 크게 움직인 자리에서 마저 체결될 수 있습니다. 텔레그램 체결 알림에
`12주 중 4주 체결 · 잔여 8주`처럼 찍히는 그 8주입니다.

대개는 손댈 것이 없습니다. 그 8주가 마음에 걸릴 때만 쓰세요.

1. GitHub 저장소 → 위쪽 **Actions** 탭
2. 왼쪽 목록에서 **"미체결 주문 취소"**
3. 오른쪽 **Run workflow** 단추 → 그대로 **Run workflow**
   (`apply`를 켜지 않았으므로 **목록만 보여주고 주문은 건드리지 않습니다**)
4. 실행이 끝나면 그 줄을 눌러 로그에서 무엇이 남아 있는지 봅니다
5. 정말 취소할 것이면 다시 **Run workflow** → `apply` 체크 → 실행

특정 종목만 취소하려면 `symbols` 칸에 종목코드를 적습니다(쉼표로 여럿:
`066970,411060`). 비워 두면 미체결 **전부**가 대상입니다.

취소되면 텔레그램으로 `🧹 미체결 주문 취소`가 옵니다.

되돌릴 수 없는 것:
- **이미 체결된 주식.** 산 것을 안 산 것으로 만들 수는 없습니다. 팔고 싶으면
  그건 매도 주문이지 취소가 아닙니다.
- **어제 주문.** 미체결은 그날 장이 끝나면 저절로 취소됩니다.

| 메시지 | 뜻 | 해야 할 일 |
|---|---|---|

| 🔴 **매도 체결** | 팔았습니다. 손익이 같이 옵니다 | 확인만 |

아무 메시지도 안 오는 날 = 신호가 없어서 거래를 안 한 날입니다.

## 7. 주간 리포트를 활용하는 법 ⭐

매주 금요일 저녁에 오는 **분석 리포트**가 이 시스템의 핵심 학습 장치입니다.

리포트에 담긴 것:
- 현재 설정 (어떤 전략, 어떤 리스크 값)
- 최근 30일 성적 (승률, 누적 손익, 손익비, 평균 보유일)
- **전략별 / 청산 사유별 / 진입 사유별** 성적 쪼개기
- 최근 매매 목록과 각각의 이유
- 지금 보유 중인 종목
- "다른 전략이었다면?" 순위
- 다기간 검증 결과

**사용법: 텔레그램에 온 내용을 전부 복사해서 Claude에게 붙여넣으세요.**
그러면 "지금 뭐가 문제인지, 뭘 바꿔야 하는지"에 대한 진단을 받을 수 있습니다.

> **승률**: 이긴 거래 비율. **손익비**: 이길 때 평균 이익 ÷ 질 때 평균 손실.
> 승률 33%여도 손익비가 3이면 본전 이상입니다. **승률만 보면 안 되는 이유**가 이것입니다.

## 9. 준비된 전략 21가지

전략을 바꾸는 건 **코드 수정 없이 대시보드 클릭 한 번**입니다.

### 추세추종 — "오르는 걸 따라 산다"
| 키 | 설명 |
|---|---|
| `golden_cross_20_60` | 단기선이 장기선을 위로 뚫으면 매수. 가장 고전적 |
| `golden_cross_5_20` | 같은 규칙의 단타 버전. 신호가 훨씬 잦음 |
| `ema_cross_12_26` | 최근 가격에 가중치를 준 이동평균 교차. 더 빠르게 반응 |
| `macd_cross` | MACD선이 신호선을 뚫으면 매수. 가장 널리 쓰이는 추세 지표 |
| `macd_cross_positive` | 위와 같되 이미 상승 국면일 때만. 하락장 반짝 반등 제외 |
| `donchian_20_10` | 20일 신고가 돌파 매수 / 10일 신저가 매도 (터틀 트레이딩) |
| `donchian_adx_filter` | 위 + 추세가 실제로 강할 때만. 횡보장 가짜 돌파 제거 |

### 평균회귀 — "너무 빠진 걸 산다"
| 키 | 설명 |
|---|---|
| `rsi_reversion` | RSI 30 반등 + 장기선 위. ⚠️ 검증 결과 **거래 0건** — 두 조건이 동시에 성립하는 일이 거의 없음. 교과서 조합이 실전에서 왜 안 되는지 보여주는 대조군 |
| `rsi2_pullback` | RSI를 2일로 짧게 잡아 "상승 중 얕은 눌림"을 노림. 위 문제를 실제로 해결한 버전 |
| `rsi_reversion_aggressive` | 기준 완화(35/65) + 필터 없음. 진입 늘지만 하락장에서 물릴 위험 큼 |
| `bollinger_reversion` | 볼린저 하단을 벗어났다 복귀하면 매수. 박스권에서 유리 |
| `bollinger_reversion_wide` | 밴드를 넓혀 더 극단적일 때만 진입 |
| `stochastic_20_80` | 과매도 구간에서의 교차를 매수 신호로 |

### 돌파·모멘텀 — "터지는 순간을 노린다"
| 키 | 설명 |
|---|---|
| `bollinger_breakout` | 상단 밴드를 거래량과 함께 뚫으면 매수 (평균회귀와 정반대 해석) |
| `volume_surge_5d` | 거래량 2배 + 2% 상승 시 매수, **5거래일 뒤 무조건 청산** |
| `volume_surge_3d` | 3배 급증만, 3일 청산. 재료 소멸 전에 빠짐 |
| `price_channel_20` | 20일 종가 신고가 돌파 매수 |
| `price_channel_60_strict` | 60일 신고가를 1% 이상 확실히 뚫어야. 가짜 돌파 최대 제거 |

### 복합
| 키 | 설명 |
|---|---|
| `ma_rsi_v1` | **현재 활성 전략.** 이동평균 + RSI 조합 (20/60/14) |
| `ma_rsi_fast5_20` | 창을 5/20/7로 좁힌 단타형 |
| `ma_rsi_loose_volume` | 거래량 기준을 1.5→1.2배로 완화 |

> **골든크로스**: 짧은 평균선이 긴 평균선을 위로 통과. 상승 전환 신호로 봅니다.
> **MACD**: 두 이동평균의 차이로 추세의 힘을 보는 지표.
> **볼린저 밴드**: 평균선 위아래로 변동성만큼 폭을 그린 띠. 띠를 벗어나면 "평소보다 심하게 움직였다"는 뜻.
> **모멘텀**: 움직이던 방향으로 더 가려는 성질.
> **평균회귀**: 많이 벗어난 가격은 결국 평균으로 돌아온다는 생각.

## 10. 전략을 바꾸기 전에 꼭 볼 것: 다기간 검증

**"백테스트 수익률이 높다"는 이유만으로 전략을 바꾸면 안 됩니다.**

> **백테스트**: 과거 데이터로 "그때 이 전략을 썼다면?"을 계산해 보는 것.
> **과최적화**: 특정 기간에만 기막히게 맞는 규칙을 찾아내 놓고 "좋은 전략"이라고 착각하는 것. 실전에서 무너지는 가장 흔한 이유.

그래서 이 시스템은 전략을 **연도별로 따로** 돌려 봅니다. 실제로 그렇게 했더니 결론이 뒤집혔습니다.

| 전략 | 2023~2024 합산 | 그런데 연도별로 보면 |
|---|---|---|
| `donchian_20_10` | **+59%** | 2022년 **−15.4%**, 2024년 **−7.8%** |
| `price_channel_20` | **+58%** | 2022년 **−22.3%** |
| `volume_surge_5d` | 평범 | 2021 +17.2 / 2022 +8.2 / 2023 +1.9 / 2024 −0.9 |

앞의 두 개는 "**좋은 2년을 골라 본 것**"이었고, 마지막 하나는 **어떤 해에도 크게 망하지 않았습니다.**

그래서 순위는 평균이 아니라 **가장 나빴던 구간 기준**으로 매깁니다 — 잘 벌 때보다 **안 망하는 게 먼저**이기 때문입니다.

*(위 숫자는 검증을 돌린 시점의 결과입니다. 최신 값은 대시보드와 주간 리포트에서 확인하세요. 아직 전략은 바꾸지 않았고, 그 결정은 사용자 몫으로 남겨 뒀습니다.)*

## 12. 자주 겪는 상황

**Q. 대시보드에 오늘 기록이 없어요**
휴장일이거나, 신호가 없어 거래를 안 한 날입니다. "최근 주문"에 아무것도 없으면 정상입니다.

**Q. 대시보드에 "복호화 실패" 경고가 떠요**
암호 키(`MUWON_MASTER_KEY`)가 바뀌었을 때 나옵니다. 저장된 비밀값을 다시 입력하면 해결됩니다.

**Q. 텔레그램이 안 와요**
대시보드 "텔레그램 알림"에 봇 토큰·채팅 ID가 들어 있는지 확인하세요. 비어 있으면 조용히 넘어갑니다.

**Q. 계좌 대조 경고가 왔어요**
내 장부와 증권사 잔고가 다르다는 뜻입니다. 시스템이 **자동으로 덮어쓰지 않습니다** — 잘못된 쪽을 자동으로 고르면 더 큰 사고가 나기 때문입니다. 사람이 확인해야 합니다.

**Q. 지금 뭘 하면 되나요?**
당분간은 **그냥 두고 관찰하는 것**이 최선입니다. 실제 매매 데이터가 몇 건 쌓여야 판단할 거리가 생깁니다. 금요일 리포트가 오면 Claude에게 붙여넣으세요.
